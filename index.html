How to join

I play on:

Java Edition (computer)

  1. Add the server

    In Minecraft, choose Multiplayer, then Add Server. Paste this into Server Address:

    mc.welloby.com

    Versions 1.7.2 to 26.3 work. 26.3 is recommended. You do not need any mods.

  2. Make a password

    Everyone does this the first time they join, premium accounts too. You have 2 minutes after you join.

    Version 1.21.6 or newer: a box appears. Type your password in the box.

    Older versions: type this in chat, with your own password two times:

    /register your password your password

    Older versions, each time you join after that, type:

    /login your password

    Use 5 to 30 characters. Pick a password that you use nowhere else.

  3. Type /accept

    Next, the server shows the Welloby Terms. To agree, type:

    /accept

    You do this once. Until then you cannot chat, build or fight.

Bedrock Edition (phone, tablet, console, Windows)

  1. Add the server

    In Minecraft, choose Play, then Servers, then Add Server. Enter this address and this port:

    bedrock.welloby.com
    Port25620

    Some consoles hide the Add Server button. If yours does, ask in #general on Discord.

  2. Make a password

    Everyone does this the first time they join. You have 2 minutes after you join.

    If a box appears, type your password in the box. If no box appears, type this in chat, with your own password two times:

    /register your password your password

    If no box appeared, each time you join after that, type:

    /login your password

    Use 5 to 30 characters. Pick a password that you use nowhere else.

  3. Type /accept

    Next, the server shows the Welloby Terms. To agree, type:

    /accept

    You do this once. Until then you cannot chat, build or fight.

Then you start at a random spot, 100 to 1,000 blocks from 0, 0, with five cookies. When you die, you drop your items.

Good to know

  • No automatic password reset. To be able to prove the account is yours, add an email: type /email add and then your email two times. Or type /discord link and send the 4-digit code to the Discord bot.
  • Voice chat. Java only, with a free proximity voice chat mod: ask in #general on Discord which one to install.
  • Daily restart. One short automatic restart a day, at 09:40 UTC.

FAQ

Top questions from new players.

Is it cracked? Can I use TLauncher?

Yes. You do not need a paid Minecraft account. Cracked (offline) launchers such as TLauncher work, and premium accounts work too.

Every player, premium included, makes a password the first time they join. The password protects your name.

Are hacked clients allowed?

Yes, and so is xray. There are no gameplay rules. The anticheat only stops things that break the server.

Which versions work?

On Java Edition, versions 1.7.2 to 26.3 work. 26.3 is recommended.

On Bedrock Edition (phone, tablet, console, Windows), use the address bedrock.welloby.com and the port 25620.

How do I join on a phone or console?

Use Minecraft Bedrock Edition.

  1. Choose Play, then Servers, then Add Server.
  2. Enter the address bedrock.welloby.com and the port 25620.
  3. Join, make a password and type /accept.

Some consoles hide the Add Server button. If yours does, ask in #general on Discord. Voice chat works on Java only.

Is there a queue?

A queue forms only when the server is full. There is no whitelist.

I lost my password. What can I do?

There is no automatic password reset. If you added an email or linked Discord, ask on Discord. That is how you prove the account is yours.

Still logged in? Protect the account now. Type /email add and then your email two times, or type /discord link and send the 4-digit code to the Discord bot.
