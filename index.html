questions people ask

does the map ever reset?

no. not for a new version, not for lag, not ever. if the world gets big we buy more disk, we don't wipe it.

is it cracked?

yes. offline names work, real accounts work. everyone picks a password on first join. don't lose it - there is no email recovery on a cracked account.

what happens when i die?

you drop everything (hard mode, keepinventory off). if you slept in a bed you respawn there, otherwise you respawn somewhere random 100-1000 blocks from 0,0.

which versions work?

the server runs 1.21.8. any java client from 1.8 to 26.2 can join. old versions will feel a little off in boats and horses. bedrock edition does not work.

how do i report a hacker?

discord, #reports: their name, what they did, when, and a clip if you have one. a clip gets them banned faster. ban appeals go in #ban-appeals, one message.

can i /tpa, /home or /rtp?

no. walk, boat, elytra, nether. the only commands are /rules /discord /kill /msg /ignore /skin and your login.

i got "wrong password"

five wrong tries in a row and the server asks for a captcha (/captcha code). if it really is your name and you forgot the password, ask in discord - we can check the register ip and reset it.
