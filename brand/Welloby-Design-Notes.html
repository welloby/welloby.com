Which file to use

WebsiteUse Logos/wordmark.svg on dark surfaces and Logos/wordmark-dark.svg on light surfaces. Both pair the W with the full name. Use the transparent PNG versions in editors that require images.
SymbolThe transparent Logos/mark files come in lava, bone (-light), and charcoal (-dark). Scale both axes together and keep the stepped upper-right edge visible.
Server listUse Icons/server-icon.png, the 64 × 64 server icon. Keep its filename when placing it in a Java Edition server folder.
BrowserUse Icons/favicon.ico for 16, 32, 48 and 64 px browser icons. A separate 32 px PNG is included.
Social headerUse Artwork/welloby-banner.png for a 1500 × 500 header. For a different aspect ratio, crop Artwork/world-art.png around the tower, then place the full logo on a quiet area.
